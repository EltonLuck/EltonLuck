### 🚀 Featured Project

**[URL Shortener — Live at eltn.link](https://eltn.link)**

A production-deployed URL shortener built with Java 21, Spring Boot, PostgreSQL, and Redis.

- Base62-encoded short links
- Redis cache-aside caching
- Per-IP rate limiting with Bucket4j
- Automated integration testing with JUnit and Testcontainers
- Docker, GitHub Actions CI, and Railway deployment
